30分割り算・余り・型の変換

数値の計算と、文字列の連結を区別する。

コード
print(7 / 2, 7 // 2, 7 % 2)

15分sortとsorted：同じ並べ替えでも違う

元を残すか、元を変えるかを選ぶ。

コード
a = [3, 1, 2]
b = sorted(a)
print(a, b)
result = a.sort()
print(result, a)
実行結果
[3, 1, 2] [1, 2, 3]
None [1, 2, 3]
なぜこうなる？
  1. 2行目：sorted(a)は、並べ替えた新しいリストを返す。元のaはまだ[3, 1, 2]。
  2. 4行目：a.sort()はa自身を並べ替える。その処理が返す値はNoneなので、resultはNone。
  3. 5行目：処理の戻り値Noneと、変更後のaを表示する。
ここだけ覚える：a = a.sort()と書くと、aがNoneになる。Noneは「値がない」を表す特別な値。

30分appendとextend：追加する単位が違う

appendは1個の要素、extendは中の要素を順に追加する。

コード
a = [1]
a.append([2, 3])
b = [1]
b.extend([2, 3])
print(a, b)
実行結果
[1, [2, 3]] [1, 2, 3]
なぜこうなる？
  1. 2行目：[2, 3]全体を1個として入れるので、入れ子になる。
  2. 4行目：2と3を1個ずつ入れるので、平らなリストになる。

30分代入とコピー：名前だけ増やしても複製にならない

別のリストが欲しいときはcopyを使う。

コード
a = [1]
b = a
c = a.copy()
b.append(2)
print(a, c)
実行結果
[1, 2] [1]
なぜこうなる？
  1. 2行目：aとbは同じリストを指す。4行目でbを変えると、aから見ても変わる。
  2. 3行目：cは別の外側リスト。今回は中身が整数なので、追加の影響を受けず[1]のまま。
ここだけ覚える：copyは浅いコピー。入れ子の内側のリストまでは複製しない。

15分rangeとcontinue：偶数の回だけ飛ばす

  3. 4行目：continueで、その回の残りを飛ばす。偶数では5行目へ進まない。
  4. 5行目：total += nはtotal = total + n。1＋3＋5で9になる。
ここだけ覚える：continueはその回を飛ばす。breakはループ全体を終わらせる。

関数：表示と返す値は別

優先A / defで処理に名前を付け、名前(...)で呼び出す。

15分printとreturnの違い

計算結果をほかの処理で使いたいならreturnで返す。

コード
def double(x):
    return x * 2
def show(x):
    print(x * 2)
a = double(3)
b = show(3)
print(a, b)
実行結果
6
6 None
なぜこうなる？
  1. 5行目：double(3)はx=3で計算し、6を返す。aに6が入り、この時点では画面に出ない。
  2. 6行目：show(3)の中のprintが6を画面に出す。しかしreturnがないので、戻り値はNone。bにはNoneが入る。
  3. 7行目：aの6とbのNoneを表示する。だから出力は2行になる。
ここだけ覚える：returnがない関数の戻り値はNone。returnに到達すると、関数はそこで終わる。

30分引数と既定値：省略したときだけ使う値

勝ち数と引き分け数から勝ち点を計算する。

コード
def points(win, draw=0):
    return win * 3 + draw
print(points(2))
print(points(draw=1, win=2))
実行結果
6
7
なぜこうなる？
  1. 1行目：winとdrawが仮引数。draw=0は、drawを渡さなかったときに使う既定値。
  2. 3行目：win=2、drawは省略したので0。2×3＋0で6。
  3. 4行目：名前で渡すキーワード引数なら、このように順番を変えられる。2×3＋1で7。
print(0 or 5)は5、print(3 and 8)は8。orは左が偽なら右を返す。andは左が真なら右を返す。0・空文字列・空のリスト・Noneなどは条件で偽になる。

15分辞書：名前を手掛かりに値を取り出す

キーと値の組を保存する。inで調べるのはキー。

コード
score = {"win": 3, "draw": 1}
print(score["win"])
print(score.get("lose", 0))
print("win" in score, 3 in score)
実行結果
3
0
True False
なぜこうなる？
  1. 2行目：キー"win"の値3を取り出す。キーはラベル、値は対応する中身。
  2. 3行目："lose"はないので、getの2番目に指定した0を返す。score["lose"]ならKeyError。
  3. 4行目："win"というキーはあるが、3というキーはない。値3があっても後半はFalse。
ここだけ覚える：Trueは真、Falseは偽。dictのinは値ではなくキーを見る。

30分内包表記：条件に合う要素から新しいリスト

forで取り出す → ifで選ぶ → 先頭の式で加工する。

コード

print(result)
実行結果
[0, 4, 8]
なぜこうなる？
  1. range(5)のnは0・1・2・3・4。ifを満たす偶数は0・2・4。
  2. 残ったnを先頭のn * 2で2倍にするので、0・4・8のリストができる。

30分集合とタプル：重複除去と、変更しない並び

集合は重複なし。タプルは要素を差し替えられない並び。

コード
print(sorted({1, 1, 2}))
print(sorted({1, 2} & {2, 3}))
t = (7,)
print(t[0], len(t))
実行結果
[1, 2]
[2]
7 1
なぜこうなる？
  1. 1行目：集合では1の重複が消える。sortedは整列したリストを返すため、表示は[]になる。
  2. 2行目：&は共通する要素。両方にある2だけ残る。|なら両方を合わせた集合になる。
  3. 3-4行目：(7,)は1要素のタプル。位置0の値は7、lenは要素数1を返す。(7)は整数。
ここだけ覚える：空の集合はset()、空の辞書は{}。集合の表示順は保証されないため、例ではsortedで順番をそろえている。

30分既定値のリストは使い回される

60分クラスとインスタンスを作る

選手ごとの名前と得点を、一緒に管理する。

コード
class Player:
    def __init__(self, name):
        self.name = name
        self.goals = 0
    def score(self):
        self.goals += 1
p = Player("Haru")
p.score()
print(p.name, p.goals)
実行結果
Haru 1
なぜこうなる？

  2. 2-4行目：__init__が初期化する。selfは今扱っているインスタンス。nameにHaru、goalsに0を持たせる。
  3. 8行目：p.score()でpのgoalsを1増やす。最後にHaruと1が出る。
ここだけ覚える：selfは慣用的な引数名。__init__内のself.goalsは個々のインスタンスの属性。

60分継承とオーバーライド

コード

    def value(self):

    def value(self):

print(b.value(), isinstance(b, A))
実行結果
3 True
なぜこうなる？

  2. この例のsuper().value()はAの処理を呼んで1を得る。2を足して3。BはAを継承するためisinstanceもTrue。

60分venvとpip：環境とパッケージを管理する

これはPythonコードではなく、ターミナルへ入力するコマンド。

コード
python3 -m venv .venv
source .venv/bin/activate
python -m pip list
実行結果
.venvという環境を作成 → 有効化 → 導入済みパッケージの一覧表示
なぜこうなる？
  1. 1行目：プロジェクト専用の仮想環境を作る。別のプロジェクトとパッケージの版を分けるため。
  2. 2行目：macOS / Linuxでその環境を有効化する例。3行目：そのPythonでpipを動かし一覧を見る。実際の表示内容は環境による。
ここだけ覚える：pipはパッケージ管理、venvは環境の分離。コマンドの-mは、指定したモジュールを実行する指定。

コード
import sys

60分statisticsとDecimal：平均と十進数

平均値と、文字列から作った正確な十進数を使う。

コード
import statistics
from decimal import Decimal
print(statistics.mean([1, 3, 5]))
print(Decimal("0.1") + Decimal("0.2"))
実行結果
3
0.3
なぜこうなる？
  1. 平均は(1＋3＋5)÷3で3。Decimalを文字列から作ると、その十進表現を保って計算できる。

30分確認3：何を何倍にする？

ifで残る数を先に選ぶ。

コード
print([n * 3 for n in range(4) if n > 1])
答えと理由を見る
答え・実行結果
[6, 9]
なぜこうなる？
  1. range(4)は0・1・2・3。このうちn > 1を満たすのは2・3。3倍して6・9になる。

  1. f(2)の中で3が画面に出る。ただしreturnがないので、yにはNoneが入り、最後にNoneが出る。

30分確認6：elseは実行される？

エラーが出る行から、どこへ移るかを追う。

コード
try:
    int("x")
except ValueError:
    print("A")
else:
    print("B")
finally:
    print("C")
答えと理由を見る
答え・実行結果
A
C
なぜこうなる？
  1. int("x")でValueError。exceptのAを実行し、elseのBは飛ばす。最後にfinallyのCを実行。
